# HCShop — E-Commerce Storefront & Admin Portal

Giao diện thương mại điện tử và cổng quản trị vận hành **HCShop** được xây dựng bằng **React + TypeScript + Vite + Tailwind CSS**.

## Tính năng chính

- **Storefront (Khách hàng)**: Danh mục sản phẩm, tìm kiếm & bộ lọc, chi tiết sản phẩm, đánh giá, giỏ hàng, danh sách yêu thích, kho mã giảm giá, thanh toán, quản lý hồ sơ, sổ địa chỉ và theo dõi đơn hàng.
- **Back-Office Portal (Nhân viên & Quản lý)**:
  - Thống kê doanh thu, sản phẩm bán chạy, báo cáo hàng tồn đọng và xuất báo cáo in/PDF.
  - Quản lý đơn hàng và cập nhật tiến trình giao hàng tuần tự.
  - Quản lý sản phẩm, danh mục, chương trình khuyến mãi, kiểm duyệt đánh giá và phân quyền tài khoản.
  - Quản lý kho hàng, phiếu nhập/xuất điều chỉnh và sổ cái biến động tồn kho.
- **Chuyển đổi vai trò nhanh**: Hỗ trợ chuyển đổi tức thì giữa *Khách hàng*, *Nhân viên*, *Quản lý* và *Khách vãng lai* ngay trong menu tài khoản.

## Chạy dự án tại máy (Local)

```bash
npm install
npm run dev
```

Đóng gói bản Production:

```bash
npm run build
```
